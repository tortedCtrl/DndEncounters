# Сборка D&D Encounters

Требуется установленный .NET 9 SDK.

- Windows x64: запустить `build-windows.bat` двойным щелчком. Исполняемый файл будет в `publish\win-x64\DndEncounters.exe`.
- Linux x64: `./build.sh linux-x64`
- macOS Apple Silicon: `./build.sh osx-arm64`
- macOS Intel: `./build.sh osx-x64`
- Windows ARM64: `./build.sh win-arm64`

Сборка выполняется для выбранной ОС и архитектуры. Создать универсальный один exe, который напрямую работает на Linux/macOS, невозможно: для каждой платформы нужен свой исполняемый файл.

## Иконка приложения

Положите вашу готовую иконку в корень проекта рядом с `DndEncounters.csproj` и `MainWindow.axaml` под именем `icon.ico`. Для надёжной совместимости используйте настоящий Windows ICO-файл с несколькими размерами (16×16, 32×32, 48×48 и 256×256); PNG, просто переименованный в `.ico`, не подойдёт. Проект подключает файл как Avalonia-ресурс, а окно ссылается на `/icon.ico`. Чтобы заменить значок, замените `icon.ico` новым ICO-файлом с тем же именем и пересоберите приложение. Если имя или путь меняется, синхронно обновите `Icon` в `MainWindow.axaml` и `AvaloniaResource` в `DndEncounters.csproj`. В исходном архиве файла иконки нет, поэтому его нужно добавить отдельно.
